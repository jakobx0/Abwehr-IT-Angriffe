>[!info] Snort Basics
>Snort ist ein Open-Source-IDS, mit dem Echtzeit-Paketanalysen in IP-Netzwerken durchgeführt werden können. Mit Snort können Angriffe wie Pufferoverflow, Stealth-Port-Scans, CGI-Angriffe (Common Gateway Interface), SMB-Tests (Server Message Block), OS-Fingerprinting-Versuche und vieles mehr erkannt werden. Snort kann für verschiedene Arbeitsweisen konfiguriert werden:
>- A) Sniffer Mode (Monitor Mode)
>- B) Packet Logger (Monitor Mode)
>- C) Network Intrusion Detection (Monitor Mode)
>- D) Network Intrusion Prevention (Inline Mode)

>[!abstract] Positionierung von Snort als IDS :
>- im Monitor Mode hinter Firewall:
>
>![[Pasted image 20250122140723.png]]
>
>IDS kann nicht jeden Angriff erkennen, da einige Teile der zum Angriff gehörenden Pakete von der Firewall blockiert werden. IDS kann daher die Signatur des Angriffs nicht vollständig erkennen.
>
>- Im Monitor Mode vor der firewall
>
>![[Pasted image 20250122140905.png]]
>
>IDS überwacht alle Angriffe von außen. Somit ist es möglich, Signaturen der Angriffe zu erkennen.

>[!abstract] Positionierung als IPS:

>

#### Snort Architektur:
>[!info] Snort Knomponenten: 
>- **Packet Decoder/Sniffer:** Bereitet Pakete für die Verarbeitung vor.
>- **Präprozessoren:** (1) Daten für die Detection Engine vorbereiten; (2) Erkennung von Anomalien in Paket-Headern; (3) Paket Defragmentierung, (4) Decodes HTTP URI; (5) Zusammenbau von TCP-Streams.
>- **Detection Engine:** Wichtigster Part. Wendet Regeln auf Pakete an.
>- **Log- und Alertsystem:** Erzeugt Warn- und Protokollnachrichten.
>- **Ausgabemodule:** Verarbeitet Warnungen und Logs und generiert die endgültige Ausgabe.
